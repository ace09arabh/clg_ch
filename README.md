# Marwari College Ranchi Website

A college website developed to present information about Marwari College Ranchi, its courses, facilities, and student registration interface.

## 🌐 Live Demo

https://ace09arabh.github.io/clg_ch/

## 📌 About the Project

This project is a front-end website designed to provide a simple and user-friendly interface for students to explore college information. It includes a homepage, login interface, registration form, About Us section, and courses section.

## ✨ Features

- **Home Page:** College introduction, image carousel, and highlights.
- **Login Page:** Sign-in interface for users.
- **Registration Page:** Form for entering personal, academic, and contact details.
- **Form Validation:** JavaScript validation for mobile number, email, and password.
- **About Us:** College information and location details.
- **Courses:** Displays course names, types, durations, and fees.
- **Image Carousel:** Automatically changes college images every four seconds.
- **Responsive Layout:** CSS styling for adapting the homepage to smaller screens.
